🧩 核心组件 LangChain

  • AgentExecutor：驱动 ReAct 循环，管理 Thought/Action/Observation
  • Tool：每个业务能力封装为 @tool 函数，含名称、描述、参数 schema
  • RetrievalQA：知识库问答链，向量召回 top-k 片段
  • Memory：ConversationBufferWindowMemory 维持多轮上下文
  • Prompt Template：约束 Agent 仅用工具获取实时数据，杜绝幻觉

🛡️ 关键设计点

  • 实时数据不靠记忆：余额/流量等动态数据一律走工具，模型只负责组织语言
  • 工具描述即提示：清晰的工具 docstring 决定路由准确率
  • 失败兜底：工具异常时回退 RAG 通用话术 + 转人工入口
  • 可追溯：每轮回答附带调用链，便于审计与质检
  • 权限校验：敏感操作（销户/改套餐）二次确认 + 身份核验

⚡ ReAct 循环示例

  • Thought：用户询问剩余流量，需查实时用量
  • Action：query_data_usage(user_id)
  • Observation：剩余 12.3GB / 30GB
  • Thought：数据已获取，组织友好回答
  • Final Answer：您本月剩余流量 12.3GB…

🔁 检索流程
  • 切分：文档按语义块切分（chunk ≈ 512 tokens），重叠 64 tokens
  • 向量化：bge-large-zh 嵌入 → 存储于向量数据库（如 Milvus / pgvector）
  • 召回：用户问题向量 top-k=4 相似片段
  • 重排：Cross-Encoder 重排，取 top-2 注入 Prompt
  • 生成：RetrievalQA 结合片段与问题生成答案并标注引用来源
